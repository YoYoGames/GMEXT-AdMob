App Open Ads

Functions for app open ads - a special format intended for monetizing your app's loading screen. App open ads can be closed at any time and are designed to be shown when your users bring your app to the foreground.

This module offers a collection of functions designed to address specific tasks and provide utilities for various purposes. Explore the available functions to make the most of the functionalities provided by this module.

admob_app_open_ad_set_ad_unit

Sets the ad unit ID used by admob_app_open_ad_load/ admob_app_open_ad_enable.


Syntax:

admob_app_open_ad_set_ad_unit(ad_unit_id)
Argument Type Description
ad_unit_id String The app open ad unit ID, from the AdMob dashboard.


Returns:

N/A

admob_app_open_ad_enable

Turns on automatic app open ads: every time the app returns to the foreground, this automatically loads (if needed) and shows an app open ad, using callback for both the load outcome and the show-lifecycle events - unless admob_app_open_ad_load/ admob_app_open_ad_show are called manually with their own callback in the meantime. This models Google's own AppOpenAdManager sample pattern for a cold-start/splash ad. There is only ever one app open ad instance - no handles, unlike the interstitial/rewarded families.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

admob_app_open_ad_enable(callback)
Argument Type Description
callback Function The function to call for both the automatic load outcome and the
automatic show-lifecycle events.


Returns:

AdMobError

AdMobError.Ok if enabling succeeded, an error code otherwise.


Triggers:

Callback

Fires once per automatic load outcome, then once per automatic show-lifecycle event whenever the app returns to the foreground. Same argument shape as admob_app_open_ad_load's and admob_app_open_ad_show's callbacks respectively.

Key Type Description
result AdMobResult The event's result.
type AdMobAppOpenAdShowEvent Present only for a show-lifecycle event (absent for a
load outcome, or when result.success is false).

admob_app_open_ad_disable

Turns off automatic app open ads, previously enabled with admob_app_open_ad_enable. The app no longer auto-loads or auto-shows an app open ad when returning to the foreground.


Syntax:

admob_app_open_ad_disable()


Returns:

N/A

admob_app_open_ad_load

Manually loads an app open ad. There is only ever one app open ad instance - loading again while one is already loaded is a no-op that immediately reports success.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

admob_app_open_ad_load(callback)
Argument Type Description
callback Function The function to call once the load completes or fails.


Returns:

AdMobError

AdMobError.Ok if the load request was accepted, an error code otherwise.


Triggers:

Callback

Fires once, when the load completes or fails.

Key Type Description
result AdMobResult The load outcome.

admob_app_open_ad_show

Manually shows the currently-loaded app open ad full-screen.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

admob_app_open_ad_show(callback)
Argument Type Description
callback Function The function to call for the ad's show-lifecycle events.


Returns:

AdMobError

AdMobError.Ok if the show request was accepted, AdMobError.NoAdsLoaded if no app open ad is currently loaded, an error code otherwise.


Triggers:

Callback

Fires once per show-lifecycle event on success; fires once with success = false and no type if the ad fails to show.

Key Type Description
result AdMobResult The event's result.
type AdMobAppOpenAdShowEvent Which show-lifecycle event this is. Absent when
result.success is false.

AdMobAppOpenAdShowEvent

The show-lifecycle events admob_app_open_ad_show's (and, when auto-showing, admob_app_open_ad_enable's) callback can fire with on success. Numeric values are extension-owned.

These constants are referenced by the following functions:

  • admob_app_open_ad_enable
  • admob_app_open_ad_show


Member Description
Shown The app open ad was displayed.
Dismissed The user closed the app open ad.
Clicked The user clicked the app open ad.
Impression The app open ad recorded an impression.
