Consent

Functions for requesting and reading the user's consent status via Google's User Messaging Platform (UMP), for GDPR/CCPA compliance.

Functions

This module offers a collection of functions designed to address specific tasks and provide utilities for various purposes. Explore the available functions to make the most of the functionalities provided by this module.

admob_consent_request_info_update

Requests the user's current consent status from Google's User Messaging Platform (UMP). Call this before any other function in this module - admob_consent_get_status/ admob_consent_get_type/admob_consent_is_form_available all report [AdMobConsentStatus](consent.md#admobconsentstatus).Unknown/[AdMobConsentType](consent.md#admobconsenttype).Unknown/false until this has completed successfully at least once.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

admob_consent_request_info_update(debug_geography, callback)
Argument Type Description
debug_geography AdMobConsentDebugGeography A debug geography to simulate (this
device is automatically registered as a test device for the simulation), or
AdMobConsentDebugGeography.Disabled for real, non-debug behavior.
callback Function The function to call once the request completes or fails.


Returns:

AdMobError

AdMobError.Ok if the request was accepted, an error code otherwise.


Triggers:

Callback

Fires once, when the consent info request completes or fails.

Key Type Description
result AdMobResult The request outcome.

admob_consent_get_status

Gets the user's current consent status, as of the last admob_consent_request_info_update call.


Syntax:

Returns:

AdMobConsentStatus

The current consent status.

admob_consent_get_type

Gets a coarse classification of the user's consent choice. This is an extension-defined convenience derived from the platform consent APIs - current Google UMP does not itself expose a personalized/non-personalized/declined classification, so treat this as a best-effort helper, not an official Google value.


Syntax:

admob_consent_get_type()


Returns:

AdMobConsentType

The classified consent type.

admob_consent_is_form_available

Checks whether a consent form is available to load, as of the last admob_consent_request_info_update call.

admob_consent_load

Loads the consent form, so it's ready to present with admob_consent_show.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

admob_consent_load(callback)
Argument Type Description
callback Function The function to call once the load completes or fails.


Returns:

AdMobError

AdMobError.Ok if the load request was accepted, an error code otherwise.


Triggers:

Callback

Fires once, when the load completes or fails.

Key Type Description
result AdMobResult The load outcome.

admob_consent_show

Presents the consent form previously loaded with admob_consent_load.

Note

If no form is currently loaded, this silently does nothing - callback never fires. Always wait for a successful admob_consent_load callback first.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

admob_consent_show(callback)
Argument Type Description
callback Function The function to call once the consent form is dismissed.


Returns:

AdMobError

AdMobError.Ok if the show request was accepted, an error code otherwise.


Triggers:

Callback

Fires once, when the user dismisses the consent form.

Key Type Description
result AdMobResult The outcome.

admob_consent_set_rdp

Sets the "Restricted Data Processing" flag Google's SDK attaches to ad requests, for CCPA compliance when a user has opted out of the sale of their personal information.


Syntax:

admob_consent_set_rdp(enabled)
Argument Type Description
enabled Boolean true to request restricted data processing on future ad requests.


Returns:

N/A

AdMobConsentDebugGeography

A geography to simulate for consent-flow testing, used by admob_consent_request_info_update. Values match Android ConsentDebugSettings.DebugGeography and iOS UMPDebugGeography.

These constants are referenced by the following functions:

  • admob_consent_request_info_update


Member Description
Disabled No debug geography - use the device's real location.
EEA Simulate a location inside the European Economic Area.
NotEEA Simulate a location outside the EEA. Deprecated by Google - use Other instead.
RegulatedUSState Simulate a location in a regulated US state.
Other Simulate a location outside the EEA and not a regulated US state.

AdMobConsentStatus

The user's consent status, as returned by admob_consent_get_status. Values follow Android's ConsentInformation.ConsentStatus numbering.

These constants are referenced by the following functions:

  • admob_consent_get_status


Member Description
Unknown Consent status is unknown - admob_consent_request_info_update hasn't
completed successfully yet.
NotRequired Consent is not required for this user.
Required Consent is required but has not yet been given.
Obtained Consent has been given (or is not required and has been acknowledged).


Back To Top

AdMobConsentType

An extension-defined classification of the user's consent choice, returned by admob_consent_get_type. Current Google UMP does not expose this classification directly - do not assume it is derived the same way on every platform.

These constants are referenced by the following functions:

  • admob_consent_get_type


Member Description
Unknown The consent type could not be classified.
NonPersonalized The user consented to non-personalized ads only.
Personalized The user consented to personalized ads.
Declined The user declined to consent (ads cannot be shown).
